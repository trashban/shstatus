# shstatus
simple, extensible shell statusline designed for use with `dwl`, `dwm` (or anything that takes constant `stdout` for bar input)

## usage
`shstatus [x]` where `x` is the time between each statusline update (length of `sleep`)

e.g for `dwl` or `dwm` **patched with `bar`**, simply pipe output into it like `shstatus [x] | dwl`
